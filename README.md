# Unit Converter
A simple C++ console program that converts different units.

How to Run

Open the project folder in Visual Studio.


Press Ctrl+F5 to build and run.


You will be asked to enter a number 1-5. You choose which you would like to use.


Then you will enter values.


Sample Input / Output
Input: Choice 3: (KG TO LBS) Value: 50 Output: 110.25 pounds.
